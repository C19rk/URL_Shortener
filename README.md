# URL Shortener Project

## Description
A simple url shortening web app that is made with React + Vite (frontend) and Express (backend) that uses Docker containerization that allows it to work flawlessly on other machines without running into issues.

### Requirements
- VSCode or any IDE
- Docker Desktop

### How to run
- git clone or download repository as zip
- Open VSCode or any other IDE
- Type this:<br>
docker-compose up --build
- Then open Docker Desktop
- Enjoy this simple project!
